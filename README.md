# Progress Bar Character

A Claude skill for planning and creating animated progress-bar characters that travel continuously from the left edge to the right edge of a video.

The character's position represents the video's progress while it performs actions that suit the video's content.

## Features

* Guided project discovery and planning
* Character and mascot design sheets
* Expression and action planning
* Character dimensions and size planning
* Storyboards and shot-by-shot video prompts
* Continuous motion and shot-transition planning
* Python tools for shot planning, frame checking, and motion tracking
* Editing guidance for assembling the final video

## Project Structure

* `SKILL.md` — Main skill instructions
* `references/` — Detailed guidance for discovery, design sheets, action planning, prompts, storyboards, and editing
* `scripts/` — Python utilities for shot planning, frame checking, and motion tracking

## How to Use

1. Download the project files.
2. Use the `SKILL.md` file and its accompanying reference files as the skill package source.
3. Follow the guided workflow to plan your character, actions, storyboards, and video prompts.
4. Use the Python scripts when their corresponding checks or calculations are required.

The skill is designed to work with video-generation tools whose supported clip durations and capabilities may differ.
